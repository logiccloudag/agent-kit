# HMI components

Generated by lc. Properties you do not set get the HMI designer's
defaults, listed per component; lc stores them in the page, so the designer and
the running HMI show the same. Set every property whose default does not fit,
e.g. a label on a colored header needs `"backgroundColor": "#ffffff00"` and
`"borderWidth": "0px"` (the label default is a white box). "Seen in real pages"
lists values from HMI pages on logiccloud dev that differ from the defaults.
Bind variables by the name listed under Inputs/Outputs.

Components with a `stateVariable` change their look only through `states`; in a
.page.json write them compactly, e.g.
`"states": [{"color": "#b8b7b8"}, {"value": 1, "color": "#8bc34a"}]`
(first entry = default / FALSE; colors as in DESIGN.md). The `states` examples below
are in the portal's
stored format, which lc generates for you.
