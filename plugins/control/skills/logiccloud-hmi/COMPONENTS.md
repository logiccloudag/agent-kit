# HMI components

Generated by lc from the HMI pages on logiccloud dev. Properties show
example values from real pages; only set what you need, the rest uses the
component's defaults. Bind variables by the name listed under Inputs/Outputs.

Components with a `stateVariable` change their look only through `states`; in a
.page.json write them compactly, e.g.
`"states": [{"color": "#b8b7b8"}, {"value": 1, "color": "#8bc34a"}]`
(first entry = default / FALSE; colors as in DESIGN.md). The `states` examples below
are in the portal's
stored format, which lc generates for you.
